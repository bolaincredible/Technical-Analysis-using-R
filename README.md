# TechnicalAnalysis

BDA400 - Data Science Tools and Techniques

Each assignment lives in its own folder.

| Folder | Description |
|---|---|
| `Assignment2/` | Technical analysis using R - preliminary stage: portfolio file, import/statistics/display functions, report |

## Running
1. Install R and RStudio, then open the `Assignment2` folder as the working directory.
2. Edit `portfolio.txt` if you want different symbols (one per line).
3. Run `source("TechnicalAnalysis_A02.R")` (or knit `TechnicalAnalysis_A02.Rmd`).
   Packages (quantmod, TTR, xts, zoo) are installed automatically if missing.
